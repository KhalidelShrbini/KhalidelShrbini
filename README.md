Featured Projects

trading terminal covering 100+ global equities (US, NL, DE, FR, UK) with real execution-cost modeling
(commission, slippage, volume-based market impact, borrow costs) and statistically rigorous validation:
walk-forward testing, Deflated Sharpe Ratio (corrects for parameter-search overfitting), Newey-West
significance testing on alpha, autocorrelation-adjusted Sharpe, and block-bootstrap confidence intervals.

from any stock.  [Live app](https://kse-backtest-platform.streamlit.app)

SQL (CTEs, window functions) for the composite scoring model, Python/pandas for the live data pipeline, Streamlit/Plotly for the visualizations (choropleth map, treemap, correlation analysis). [Live app](https://khalid-entrepreneurial-ecosystems.streamlit.app)
